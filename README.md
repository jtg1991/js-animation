# js-animation

**The Very Hungry Black Hole**: a 2D doodle-style canvas animation of a black hole swallowing the Earth.

Open `index.html` in a browser. No build step or dependencies (the handwritten font loads from Google Fonts, with a cursive fallback offline).

- Click or press `R` to replay
- Press `Space` to pause

The whole story runs for 18 seconds and then loops.
